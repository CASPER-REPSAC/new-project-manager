# 페이지 명세

### 공통 영역 (Global Header & Navigation)

- **글로벌 네비게이션 바 (GNB)**
    
    - **서비스 로고 및 이름:** 클릭 시 홈(프로젝트 매니저 메인)으로 이동
        
    - **서비스 전환 탭:** `프로젝트 매니저` ↔ `마크다운 공간` 간 원클릭 스위칭
        
    - **통합 검색 바:** 프로젝트 및 마크다운 문서 전체 텍스트 실시간 검색 (FR-3.3, FR-19)
        
    - **유저 영역:** SSO 로그인/로그아웃, 알림(@멘션, 댓글 알림 등) 드롭다운, 프로필 및 마이페이지 링크 (FR-1, FR-5.5)
        

### 프로젝트 매니저 메인 페이지

프로젝트 목록을 탐색하고 새로운 프로젝트를 등록하거나 개별 프로젝트 상세 내용을 확인하는 공간입니다.

- **1. 프로젝트 목록 페이지 (Main View)**
    
    - **1.1 상단 컨트롤 & 필터 바**
        
        - **뷰 전환 컨트롤러:** 카드(Grid) 뷰 / 리스트(List) 뷰 / 테이블(Table) 뷰 전환 버튼 (FR-3.1)
            
        - **정렬 셀렉터:** 최신 등록순, 인기순(좋아요/조회수), 댓글 많은 순, 발표 일정순 정렬 (FR-3.2)
            
        - **다중 필터링 툴바:** 진행 상태, 기술 스택(태그), 참여 연도/학기, 작성자 조건 검색 (FR-3.4)
            
        - **액션 버튼:** `+ 새 프로젝트 등록` 버튼
            
    - **1.2 프로젝트 목록 표시 영역**
        
        - 선택된 뷰(카드/리스트/테이블)에 따른 프로젝트 아이템 렌더링
            
        - 각 아이템: 대표 썸네일, 제목, 한 줄 요약, 기술 스택 태그, 작성자/팀원 아바타, 좋아요 수, 댓글 수 표시
            
- **2. 프로젝트 상세 페이지 (Sub-page)**
    
    - **2.1 프로젝트 헤더 & 메타데이터 영역**
        
        - 제목, 한 줄 요약, 진행 상태 배지(기획 중/개발 중/완료 등), 참여 팀원(클릭 시 프로필 이동), 기술 스택 (FR-2.1, FR-2.3, FR-6.1)
            
        - **액션 툴바:** 좋아요(북마크) 버튼, 공유(딥링크) 버튼, 프로젝트 수정/삭제 버튼 (FR-4.2, FR-4.4)
            
    - **2.2 PDF 발표 자료 뷰어 영역 (FR-4.1)**
        
        - 임베드된 전용 PDF 뷰어 (좌우 슬라이드 이동, 페이지 제어바, 전체 화면, 확대/축소)
            
        - 발표 자료 버전 이력 드롭다운 (이전 버전 발표 자료 선택 및 조회) (FR-2.4)
            
    - **2.3 노션라이크 상세 보고서 영역 (FR-4.3)**
        
        - 마크다운 리치 텍스트로 작성된 프로젝트 상세 설명 (다이어그램, 코드 블록 등)
            
        - **연동 공간 위젯:** 연관된 마크다운 공간의 문서(회의록, API 명세서 등) 및 마일스톤 캘린더 바로가기 탭 (FR-6.2, FR-6.3)
            
    - **2.4 소스 및 영상 첨부 영역**
        
        - 데모 영상(YouTube/Vimeo 임베드) 플레이어, 소스 코드 아카이브(ZIP) 다운로드 버튼 (FR-2.2)
            
    - **2.5 Q&A 및 댓글 상호작용 영역 (FR-5)**
        
        - 마크다운 지원 댓글 입력 창 (`질문` 태그 체크박스, `@유저` 멘션, `#p페이지` 슬라이드 태그 기능 지원)
            
        - 댓글 및 대댓글(Thread) 목록 (`해결됨` 상태 토글 버튼 표시)
            
- **3. 프로젝트 등록 및 수정 페이지 (Sub-page)**
    
    - **3.1 메타데이터 폼:** 제목, 요약, 진행 기간, 상태, 기술 스택, 참여 팀원 지정 폼 (FR-2.1)
        
    - **3.2 멀티미디어 업로더:** PDF 발표 자료, 썸네일 이미지, 소스 압축 파일, 영상 링크 첨부 영역 (FR-2.2)
        
    - **3.3 본문 에디터:** 노션라이크 마크다운 에디터를 활용한 상세 보고서 작성 영역
        
- **4. 유저별 프로젝트 모아보기 페이지 (Sub-page / 필터링 뷰)**
    
    - **4.1 작성자 프로필 요약:** 프로필 이미지, 이름, 학과/소속, 간단한 소개
        
    - **4.2 참여 프로젝트 목록:** 해당 작성자가 참여/기여한 프로젝트만 필터링된 뷰 (FR-3.5, FR-6.1)
        

### 마크다운 공간 메인 페이지

계층형 문서 구조를 관리하고, 블록 기반 마크다운 문서 및 노션라이크 데이터베이스를 작성·협업하는 공간입니다.

- **1. 좌측 사이드바 (Sidebar Navigation)**
    
    - **1.1 워크스페이스 & 컬렉션 트리:** 팀/주제별 컬렉션 및 무한 중첩 페이지 계층 구조 트리 (FR-11, FR-18)
        
    - **1.2 빠른 접근 바:** 즐겨찾기(Favorites), 최근 열어본 문서, 유저 북마크 목록
        
    - **1.3 관리자 메뉴:** 워크스페이스 권한 설정, 휴지통, 가져오기/내보내기 메뉴 (FR-24, FR-26)
        
- **2. 마크다운 페이지 에디터 (Main Workspace)**
    
    - **2.1 상단 문서 네비게이션 바**
        
        - **동적 브레드크럼:** 현재 문서의 계층 경로 표시 및 상위 폴더 이동 (FR-12)
            
        - **우측 액션 버튼:**
            
            - 변경 이력(History) 및 Diff 비교 버튼 (FR-21)
                
            - 외부 퍼블리싱/공유(비밀번호 및 만료일 설정) 버튼 (FR-25)
                
            - 페이지 설정(내보내기: md, html, pdf / 페이지 권한 설정) (FR-24, FR-27)
                
    - **2.2 블록 하이브리드 본문 에디터 영역**
        
        - 문서 타이틀 및 아이콘/커버 이미지 설정
            
        - **블록 조작 캔버스:** 단축키 실시간 변환, 슬래시(`/`) 커맨드 호출, 드래그 앤 드롭 재배치, 좌우 다단 레이아웃 지원 (FR-7, FR-8, FR-9)
            
        - **리치 블록 지원:** 코드 블록(Syntax Highlighting), LaTeX 수식 블록, 외부 서비스 임베드, 하위 페이지 링킹 (FR-10, FR-11)
            
    - **2.3 협업 및 컨텍스트 레이어**
        
        - 실시간 공동 편집 커서 및 참여자 아바타 표시 (FR-22)
            
        - 텍스트 선택 시 생성되는 인라인 댓글 및 스레드 사이드 패널 (FR-23)
            
    - **2.4 하단 메타 정보 영역**
        
        - **백링크(Backlinks):** 현재 페이지를 참조하고 있는 다른 문서들의 자동 수집 목록 (FR-20)
            
- **3. 데이터베이스 뷰 페이지 (Full-page Database View)**
    
    - **3.1 데이터베이스 상단 컨트롤 바**
        
        - **다중 뷰 전환 탭:** 테이블(Table) / 칸반 보드(Board) / 캘린더(Calendar) / 갤러리(Gallery) / 리스트(List) 뷰 추가 및 전환 (FR-15)
            
        - **데이터 제어 툴바:** 속성별 정렬(Sort), 조건 필터(Filter), 그룹화(Group by), 검색 바 (FR-16)
            
    - **3.2 뷰어 캔버스 (선택된 뷰에 따라 동적 변경)**
        
        - **테이블 뷰:** 스프레드시트 형태, 하단 열별 롤업(합산/평균/개수) 요약 행 표시 (FR-17)
            
        - **칸반 뷰:** 선택(Select) 속성 기준 열 구성, 드래그 앤 드롭 상태 변경
            
        - **캘린더 뷰:** 날짜(Date) 속성 기준 월간/주간 일정 표시
            
        - **갤러리 뷰:** 첨부 이미지 또는 본문 썸네일 강조 카드 레이아웃
            
    - **3.3 속성(Property) 관리 모달**
        
        - 텍스트, 숫자, 날짜, 유저 지정, 선택, 관계형(Relation), 수식(Formula) 등 속성 열 추가/수정 (FR-14, FR-17)
            
- **4. 관리 및 시스템 설정 페이지 (Sub-page)**
    
    - **4.1 변경 이력 및 복원 페이지:** 타임라인 슬라이더, 버전 간 텍스트 Diff 하이라이팅, 과거 시점 복원 버튼 (FR-21)
        
    - **4.2 권한 관리 페이지:** 유저/그룹별 4단계 권한(관리자, 편집자, 댓글 작성자, 뷰어) 설정 테이블 (FR-24)
        
    - **4.3 시스템 연동 및 웹훅 설정:** 외부 서버 웹훅 URL 등록, 이벤트 트리거 설정, API 토큰 관리 (FR-28, FR-29)
        
    - **4.4 데이터 가져오기/내보내기 마법사:** Notion Zip, MD, CSV 일괄 업로드 및 다운로드 인터페이스 (FR-26, FR-27)
